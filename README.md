# CODNUVIA STUDIO — Portafolio de alto impacto

Incluye página principal y cinco conceptos independientes: BRASA (restaurante editorial), ÉTER (belleza premium), NOVA (streetwear con carrito), TORQUE (automotriz de alto contraste) y alto. (consultoría corporativa). Todos son **demos ficticios**, no trabajos de clientes.

## Publicación
Sube **todo el contenido de esta carpeta** (no la carpeta contenedora) a la raíz de un repositorio público en GitHub. Activa Settings → Pages → Deploy from branch → main → /(root).

Las rutas relativas funcionan desde un repositorio GitHub Pages. Los demos enlazan al portafolio con `../index.html#proyectos`.

## Configuración
En `assets/config.js`, configura tu número de WhatsApp. Revisa las tarifas y contenidos de `index.html`. Las imágenes son externas y requieren conexión a Internet; verifica derechos y condiciones de uso antes de publicarlas comercialmente. Los formularios de demostración no envían datos y el carrito no procesa pagos.

## Pruebas
Abre index.html, visita las cinco tarjetas, prueba el carrito NOVA y los formularios, vuelve al portafolio, y comprueba todo de nuevo en la URL publicada.
